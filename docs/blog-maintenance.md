# Blog maintenance

The site keeps its original indigo/cyan gradient, glass cards and light/dark visual identity. It remains a static Astro site; no backend or publishing account is required.

## Publishing

Edit `src/content/blog/*.md`, retain its filename to preserve the URL, set `lang` to `zh-CN` or `en`, and use `updatedDate` only when the content changes. Include a real description. An English translation uses the same slug plus `-en`; only actual pairs get language alternates. The `hello-world` sample remains accessible but is excluded from discovery and marked noindex.

`npm ci && npm run build` builds the site. `node --test tests/site.test.mjs` tests feeds and content helpers. GitHub Pages deploys after successful checks.

## RSS and indexing

- `/rss.xml`: all articles
- `/rss/zh.xml`: Chinese
- `/rss/en.xml`: English
- `/subscribe/`: human-readable subscription page
- `/robots.txt`: crawl permission and sitemap discovery
- `/sitemap-index.xml`: generated by the existing Astro sitemap integration

Feeds contain summaries and stable canonical GUIDs. They need no external service. Sitemap submission in Google Search Console can help discovery; search-engine indexing is not guaranteed. Site verification requires the owner's actual verification record, which must never be invented.

## Images and page weight

Medical-training photographs are stored under `public/images/compressed-modernity/photos/`. Credits, original source pages and licences appear next to the images and in `docs/medical-training-photo-sources.json`. WebP files are resized proportionally, not cropped or retouched. Only pages containing math or Mermaid load their corresponding runtimes. Reduced-motion preferences disable decorative animation.

## WeChat

Automatic WeChat publishing has been removed. Historical manually formatted exports in `wechat_version/` are retained as source material. Do not add application secrets to this repository.
