# Jay’s Blog

Jia-Hao Ji’s research profile and writing, published at **https://jiahaoblog.com**.

A static Astro site. No CMS, database, hosted search, WeChat uploader or self-hosted runner is required.

## Run

```sh
npm ci
npm run dev
npm run build
npm run check:site
```

The last command checks built RSS feeds, canonical URLs, sitemap coverage, language alternates, article metadata and site-navigation links. CI also stages the CV PDFs before running it; for a local check, place the three compiled CVs from `cv/` in `public/` and copy the one-page English CV to `public/resume_long.pdf`.

## Publish

Edit `src/content/blog/*.md` and push to `main`. The workflow installs locked dependencies, builds static HTML, validates output and deploys to GitHub Pages. Compiled CVs are cached by their source inputs; updating an article does not normally recompile them. Pull requests build and run desktop/mobile browser checks without deploying.

All existing article paths are preserved. `/zh/` is a real Chinese homepage, with reciprocal language links to `/`. The complete writing archive is present in HTML even with JavaScript disabled; browser-side search filters titles, descriptions and optional tags.

## Content

```yaml
---
title: "A specific, descriptive title"
description: "A useful summary written for readers."
pubDate: 2026-09-09
lang: zh-CN
# updatedDate: 2026-09-10  # Only after a substantive content change.
# tags: [AI, medicine]
# translationKey: shared-key-for-two-language-versions
# draft: true
# math: true
# mermaid: true
---
```

Drafts and future-dated posts are excluded from published routes and feeds. Future-dated posts appear after a build on or after their publication day (UTC). There is no background scheduler. Existing `-en` article pairs are recognized; use `translationKey` for new pairs with different slugs. Each translated page keeps its own canonical URL.

`src/lib/site.ts` holds the shared identity, contact and selected research information. `src/components/HomePage.astro` and `ProfilePage.astro` share their layouts across both languages. About-page narratives stay in `src/content/about/`. The optimized portrait is `src/assets/portrait.jpg`; `public/avatar.jpg` is retained as a legacy URL and CV asset.

## Subscription and discovery

- `/rss.xml` — all languages, up to 50 articles.
- `/rss/zh.xml` — Chinese articles.
- `/rss/en.xml` — English articles.
- `/subscribe/` — reader-facing subscription instructions.
- `/sitemap-index.xml` — generated by the existing Astro sitemap integration.
- `/robots.txt` — allows crawling and points to the sitemap.

Feeds contain title, summary, author, publication date and a stable canonical link, not a lossy copy of interactive article HTML. They update with each build. Article pages expose BlogPosting and breadcrumb JSON-LD; translated pages use reciprocal `hreflang` links. Site pages render real content without JavaScript. No search ranking or indexing outcome is guaranteed.

To monitor Google indexing, verify the domain in Google Search Console and submit `https://jiahaoblog.com/sitemap-index.xml`. That account-level verification is separate from the site code. Do not commit private verification credentials or API secrets.

## Optional browser checks

```sh
python -m pip install playwright==1.55.0
python -m playwright install chromium
python scripts/check-ui.py
```

Screenshots and audit summaries are written to `site-review/`. CI makes them available as a short-lived artifact. Existing raw HTML, mathematical notation, Mermaid diagrams, article-specific scripts and interactive assets remain supported; the shared layout loads technical libraries only for posts that need them.

## Removed integration

The automatic WeChat upload workflow, uploader and its Python dependencies have been removed. Archived manual layouts in `wechat_version/` are retained as content, not connected to a publishing service. Any previously configured WeChat repository secrets can be deleted from GitHub’s secret store; none are used by this site.
